# overapi documentation

overapi turns an API you can't rewrite into tools your agents can safely use: bring it in, use it, make it agent-ready, and publish it as an MCP server. These guides go one step past the [README](../README.md).

| Guide | Read it when |
|---|---|
| [Getting started](getting-started.md) | You've just installed overapi and want your first API in Claude Code |
| [Record a web app](record-a-web-app.md) | The API you need has no docs: it's whatever a website calls behind the page |
| [Sign-in](sign-in.md) | Your API needs a token, a login, OAuth, a client certificate, or a browser session |
| [Sharing and safety](sharing-and-safety.md) | You want to commit a project for your team, or need to know what agents can and can't do |
| [Command line](cli.md) | You want to import, check, serve or test from a terminal or CI |

Something missing or wrong? [Open an issue](https://github.com/overcodelions/overapi/issues). Security problems go through a [private advisory](../SECURITY.md) instead.
